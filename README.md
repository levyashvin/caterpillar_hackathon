# CAT Inspect AI — Caterpillar CODE-A-THON 2024 Finalist Submission

Our project entry for the Caterpillar CODE-A-THON 2024, a 48-hour hackathon that brought together over 1,500 students to address real-world digital transformation challenges.

Our team created CAT Inspect AI, a voice-guided, AI-powered inspection tool that helps technicians do equipment inspections hands-free, efficiently, and intuitively.

---

## Problem Statement: "Next Gen Inspections"

CODE-A-THON 2024 — 48-Hour Hackathon  
Problem Statement 1  
Develop a next-generation capability for service technicians to record equipment inspections without having to manually write or type.

Expected Outcomes:
- Voice-guided inspections via smart prompts
- Voice-to-text findings with keyword triggers
- Auto-capture image and data when keywords like "Broken", "Rust", "Low" are recognized
- Multi-language support (English, Hindi)
- PDF report generation with structured inspection summary
- UI for tracking, listing, and retrieving inspection history

---

## Project Summary

Inspections are vital in preventing equipment failure and reducing service costs. CAT Inspect AI allows technicians to:
- Conduct inspections using voice commands
- Automatically capture form fields and images
- Seamlessly validate and export detailed reports
- Access reports anytime from the dashboard

Sample Sections:
- Tires – Pressure, condition, images
- Battery – Voltage, water level, rust/leak detection
- Exterior – Rust, dents, oil leaks
- Brakes – Fluid levels and brake conditions
- Engine – Oil condition and color, leaks
- Voice of Customer – Feedback and related images

---

## Key Features

- Voice-Based Data Entry  
- Form Auto-fill with Smart Prompts  
- Image Capture Triggered by Keywords  
- Multi-Language Support (English, Hindi)  
- PDF Report Generation with Images  
- UI for Viewing, Filtering, and Searching Reports  
- Optional Geo-coordinates for Remote Inspections

```bash

```

### Run

#### Flutter App

